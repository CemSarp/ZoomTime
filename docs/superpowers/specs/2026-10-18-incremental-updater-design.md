# Free incremental updater design

User approved2026-10-18. Replace full-ZIP/manual recovery with Check → Update → Restart. Published builds are produced centrally; recipients need no compiler. Use Electron44.7.1's bundled Squirrel native delta updater, with automatic verified full fallback. Keep distribution free. Allow one identity migration with possible approvals; do not claim future permission retention without actual two-Mac A→B→C evidence.

Use one persistent self-signed code-signing identity in the developer's login Keychain, encrypted recovery backup outside the repository, public certificate pins in source. Sign main/nested/helper code consistently. Certificate-pinned requirements only; no identifier-only requirement or ad-hoc fallback. Do not change trust settings, TCC, Gatekeeper, sandbox/isolation, entitlements, fuses or TLS policy. Preserve app/helper IDs, profiles and historical artifacts.

Keep GitHub numeric/prerelease discovery and strict bounded metadata/download validation. Check never downloads/stages. Update explicitly downloads/stages and authorizes installation on next quit; Restart invokes native install only when no call/hosted group/check/capture is active. No automatic check, forced restart, Finder step or new public service. Preserve standard and Experimental installation paths plus a verified rollback copy. Keep normal updates native; legacy installer remains migration/recovery history.

Release assets: full signed arm64 ZIP, previous-signed-release delta where smaller/available, checksums/provenance and versioned Squirrel JSON feed. Pin BinaryDelta build tool; normalize permissions before final signing, preserve exact shipped bundles, apply each patch locally and verify target identity/bytes before upload. If security or permission continuity fails, preserve the working app and report the constraint, never bypass it. Independent screen permission bug and physical group acceptance remain pending.

This binds target version and full/delta hashes independently of GitHub metadata and prevents substituting a patch that reconstructs a different previously signed version.
