# ZoomTime0.5.0 — signed updates, local volume and live audio controls (prerelease)

**Reduce speaker echo** now switches on/off during a call or device check without leaving/rejoining. The camera, call connections, mute and local playback levels stay intact; a microphone swap may briefly pause outgoing audio. The Experimental label is removed and a collapsed **How it works** section explains WebRTC processing. Unsupported devices/permissions still receive honest status; physical acoustic effectiveness remains unverified.

The pre-publication UI pass adds state-aware microphone/camera symbols in Normal/Mini and a three-dot-only compact menu. Consistent settings/input spacing, switches, keyboard focus, reduced motion, long-name wrapping and clearer modal/Mini errors are included. Full control inventory and actual/pending evidence: [UI/UX review](../UI_UX_REVIEW.md).

Overall and individual participant volume controls are included in **•••** in Normal and Mini modes. Overall call volume is remembered; each participant's level lasts for their current participation. Both range from0–100%, multiply together and affect only local playback. macOS output volume still sets the maximum. Muting your microphone remains separate.

Free, centrally built updates now use Electron's bundled native updater. After this one migration, Check → Update ZoomTime → Restart to update normally downloads a signed delta, automatically using a full verified ZIP when needed. A prepared update installs on the next ordinary quit; Restart refuses active calls/hosted groups, device checks or local screen capture. Standard and Experimental app names directly inside Applications are supported and a verified previous bundle is retained. Pairing/settings remain outside the app.

This release establishes one persistent private self-signed identity and certificate-authenticated update feeds. Old ad-hoc versions need one full migration update with possible normal Gatekeeper, Keychain/media approvals. Older Experimental installers may need one last Finder replacement. No compiler is needed by recipients and no background checks are added. See [migration/update guide](../UPDATES.md).

**Known screen-share/screen-capture permission bug remains unresolved.** Screen Recording can repeat prompts or remain denied. Partner screen transmission is still not implemented. Stable signing does not prove prompt-free future updates. Two actual Macs must test migration and two subsequent updates for camera, microphone, Screen Recording and Keychain continuity. Real group/network/hardware/long-session acceptance also remains pending.

## Installation and verification

This first persistent-signed migration ships a full arm64 ZIP plus an authenticated native feed/signature, checksums, build provenance and installation guide. No delta from the old ad-hoc0.4.0 signature is advertised. Following migration, compatible future releases can use deltas with verified full fallback. Put ZoomTime.app or ZoomTime Experimental.app directly in /Applications or ~/Applications; nested testing folders are not supported by the in-app installer. Old renamed previews may need one final Finder migration. [Installation](../../INSTALL.md) · [Update guide](../UPDATES.md).

Local unit, generated2–5-client media, UI/package, signing and native A→B→C/delta/full-fallback/failure checks are recorded in [verification](../VERIFICATION.md). These are local tests and disposable fixtures, not two-Mac acoustic/permission or installed-update acceptance. This prerelease is explicitly published for testing with the remaining physical gates pending. Historical releases, installed apps, pairing and backups are preserved.
