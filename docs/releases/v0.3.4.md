ZoomTime 0.3.4 adds user-initiated install-and-restart updates, independent floating-window settings and experimental speaker echo reduction. It also includes a macOS panel change intended to address Mini disappearing over Safari full screen; controlled Safari regression testing is still pending.

## Changes

- **Install and restart:** after a verified GitHub download, quit and replace the application through an explicit button. Pairing/preferences stay in your profile; the previous application is retained beside ZoomTime as a recovery backup. Installation is blocked during calls or camera/microphone checks. No background updates, administrator helper, source compilation or security bypass.
- **Separate always-on-top switches** for the regular and Mini windows in Settings. Defaults remain regular off and Mini on. Both choices persist independently.
- **Reduce speaker echo · Experimental:** an optional, default-off setting asks WebRTC to use Mac playback as an echo-cancellation reference for the next call or device check. Actual track settings determine whether it reports applied or unavailable. Unsupported configurations retain ordinary echo cancellation. No separate playback recording or transmission; effectiveness on real speakers is unverified and headphones remain the reliable option.
- **Safari overlay candidate:** the same call window now uses a macOS panel, preserving the renderer/media session. An isolated probe supports this change, but it is not a verified full-screen fix. Regular mode can follow all Spaces even with always-on-top disabled; full-screen, Dock and focus regression tests remain pending.
- Preserve the updated **Reset Pairing** and **Settings** button labels.

## Download and installation

Requires macOS 14 or newer. No Node, Xcode, GitHub account or paid service is required.

- [Intel / x64](https://github.com/CemSarp/ZoomTime/releases/download/v0.3.4/ZoomTime-darwin-x64-0.3.4.zip)
- [Installation guide](https://github.com/CemSarp/ZoomTime/releases/download/v0.3.4/INSTALL.md) · [SHA-256 checksums](https://github.com/CemSarp/ZoomTime/releases/download/v0.3.4/SHA256SUMS) · [Build provenance](https://github.com/CemSarp/ZoomTime/releases/download/v0.3.4/build-manifest.json)

**Upgrading from 0.3.2/0.3.3:** Check for Updates can download this prerelease, but that older app still finishes installation in Finder. End your call, quit ZoomTime, extract the ZIP and drag ZoomTime.app into Applications, choosing Replace. You do not need to delete the old app or reset pairing. Version 0.2.0 needs the matching direct download.

**Once this build is installed:** future higher published versions offer **Check → Download → Install and restart**. Install ZoomTime in `/Applications` or your own `~/Applications`; both the app and containing folder must be writable for your user. Protected locations use the verified Finder fallback. Earlier local previews with the same version number are not offered an equal-version update; install this release once manually.

Private builds are ad-hoc signed and unnotarized. macOS may require [per-app approval](https://support.apple.com/en-gb/102445), Keychain or media consent. Gatekeeper and quarantine remain enabled. The installer preserves the previous app, but a crash/power loss between replacement renames may require restoring the `ZoomTime-previous-…` backup in Finder. Backups and staging files are retained, using additional disk space. No independent notarized publisher identity is provided.

## Verification and remaining limits

- 83 unit tests pass in the completed candidate verification, including ZIP validation, signed fixture staging, helper handoff/parent binding, backup/rollback and updater state/hash checks. Typecheck and lint pass.
- Both architecture packages pass code-signature, version/CPU/privacy metadata, security fuse, bundled-payload/source equality, ZIP integrity and SHA-256 checks. Intel hardware execution is untested.
- The prior real Chromium/WebRTC suite passed with generated media, including optional echo-cancellation mode and lifecycle cleanup. It does not prove hardware acoustic suppression or two-network connectivity.
- Installer tests cover real signed fixtures, helper readiness/parent waiting and rejection of invalid packaged-helper jobs. Actual downloaded installed-app replacement, Gatekeeper approval and healthy restart remain unverified.

**Prerelease:** controlled Safari/regular-window regressions, partner-Mac installation and routing, actual two-network/no-TURN media, hardware echo reduction and the three-hour movie session remain pending. Publication is explicitly requested distribution of a test candidate, not completion of those acceptance gates. No live tailnet configuration, pairing invitation, STUN/TURN service, recording or analytics is added.
